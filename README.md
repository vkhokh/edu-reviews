# EduReviews

Сервис отзывов о преподавателях и курсах вуза. Студенты честно оценивают
образовательную программу по нескольким критериям, кафедра получает
обратную связь и анонимную сводную статистику, отзыв проходит модерацию
перед публикацией, а рейтинг преподавателя пересчитывается автоматически.

Курсовой проект по предмету «Веб-разработка» (Ruby on Rails).

## Статус

**Чек-поинт 1** — готовы экраны регистрации и входа: своя аутентификация на
`has_secure_password` (bcrypt), без Devise, в едином визуальном стиле,
который будет использоваться во всём приложении.

Остальные экраны (каталог кафедр/курсов/преподавателей, профиль
преподавателя, форма отзыва, сводная статистика кафедры) — в разработке,
макеты уже согласованы.

## Технологии

- Ruby on Rails
- SQLite (разработка)
- bcrypt (`has_secure_password`) — аутентификация
- Собственный CSS, без UI-фреймворков (Bootstrap/Tailwind)
- Шрифты: Space Grotesk (заголовки), Work Sans (текст)

## Критерии оценки преподавателя

Каждый отзыв оценивает преподавателя по трём критериям:

- ясность объяснения
- объективность на экзамене
- нагрузка

## Установка и запуск

```bash
git clone https://github.com/vkhokh/edu-reviews.git
cd edu-reviews
bundle install
bin/rails db:create
bin/rails db:migrate
bin/rails server
```

Приложение будет доступно на `http://localhost:3000`.

## Модерация и приватность

- Отзыв не публикуется сразу — сначала его проверяет кафедра.
- Рейтинг преподавателя и сводная статистика кафедры пересчитываются
  автоматически по уже прошедшим модерацию отзывам.
- Отзывы анонимны для остальных пользователей.

## Планы

- Каталог кафедр, курсов и преподавателей с фильтрами и поиском
- Профиль преподавателя: рейтинг по критериям и лента отзывов
- Форма отправки отзыва с оценками по критериям
- Кабинет кафедры: сводная статистика и очередь модерации
